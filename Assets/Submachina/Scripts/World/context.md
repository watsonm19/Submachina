# World Systems

Procedural world generation and the world entities the submarine interacts with (rocks, mining resources, O2 bubbles, enemies). World objects never hold a submarine reference — they resolve the sub from context (`Submarine.FindNearest`, `GetComponentInParent<Submarine>`, or a reference injected at spawn). See `../Submarine/context.md` for the facade these objects target.

## Generation

- **ChunkSpawner** — generates the world as a persistent grid of chunks around the camera. Pre-spawns every cell within `spawnRadius` (e.g. a 7×7 ring) and **never despawns** them. Maps grid coords → world space with `FloorToInt` (correct for negative Y), filters out cells above the surface (Y ≥ 0), and instantiates one `WorldChunk` per cell, handing it the rock/resource/enemy/O2 prefabs. Keyed dictionary keeps chunks unique. Depends on `Camera.main`.
- **WorldChunk** — populates a single chunk via `Initialize(topY, height, halfWidth, depth, rock, resource, enemy, o2)`. Generation is **depth-scaled** (denser/harder deeper): rocks (wall protrusions + center obstacles), mining resources (outer band), passive O2 bubbles (sparse, central, only past ~3 m — combat is the main air source), and enemies (from a ~20 m grace depth, lerping 1→4 over depth, kept central for patrol room). Spawned entities are parented under the chunk.
- **WorldBoundary** — attach to the camera. Creates invisible left/right `BoxCollider2D` walls parented to the camera so they scroll with the viewport. `halfWidth` must match `ChunkSpawner`'s cell half-width so the walls align with the generated world edges; `wallHeight` covers the view plus buffer.

## Entities

- **EnemyController** — sea-creature AI: Patrol → Chase → WindUp → Attacking → AttackCooldown (+ terminal Dead) state machine. Acquires the player via `Submarine.FindNearest(transform.position)` in Start and caches its `Health`. Detection uses `detectionRadius`/`deaggroRadius` hysteresis; the attack telegraphs (orange tint + DOTween `DOPunchScale` on an intent indicator) then lunges (red, `lungeSpeed`), dealing `attackDamage` to the player's `Health` on contact (guarded to once per lunge). Subscribes to its own `Health.onDeath` to drop `o2BubblePrefab` ×`bubbleDropCount`. Composes with `HitFlash` (which preserves these state tints). Force-free Rigidbody2D driven by `linearVelocity`.
- **MiningResource** — laser-mineable node (on the "Resource" layer, trigger `CircleCollider2D`). `SetMiningProgress(0..1)` is called by `MiningLaser` each frame the beam holds it, lerping the sprite toward white. `Collect(Submarine sub, airMultiplier = 1)` — called by the laser at completion (separated so magnet/auto upgrades can also call it) — awards `sub.Resources.AddResources(...)` and rolls `scrapDropChance` for `sub.Scrap.AddScrap()`.
- **O2Pickup** — air bubble (enemy drop or passive scatter; trigger `CircleCollider2D`). `Collect(Submarine sub, airMultiplier = 1)` restores `sub.O2.RestoreCapacity(...)` and `sub.O2.AddAir(replenish × multiplier)`, fires `onCollected`, then self-destructs. `collectOnContact` is **off by default** — collection normally goes through `O2PickupPump`'s sweet-spot mechanic (which calls `Collect` with a graded multiplier); when on, `OnTriggerEnter2D` resolves the sub via `other.GetComponentInParent<Submarine>()`.
