# World / Creatures

Procedurally animated sea creatures built on `Core.ProceduralAnimation`
(see that folder's context.md for the solver/renderer layer). All combat
creatures follow the standard enemy recipe: extend `EnemyBase`, components
`Rigidbody2D` + `Collider2D` + `Health` + `HitReceiver`, Enemy layer, damage
via the RammingEnemy collision pattern (`Hull.EvaluateAttack` → `Health.TakeDamage`),
spawning via `SpawnRule` assets — no code registration.

The design principle throughout: **the state machine speaks through body
language**. Brains drive `ChainSimulator.WaveFrequency/AmplitudeMultiplier`,
`RadialMeshRenderer.Squash/RimOffsets`, and the shader's `_FlashAmount` /
`_EmissionColor` (via MaterialPropertyBlock) so players read intent from motion,
not UI.

## Creatures

- **EelEnemy** — sinuous chaser. Lurk → Hunt (weaving pursuit) → WindUp (coil
  telegraph: wave frequency spikes, body flashes) → Strike (rigid straight
  lunge, contact damage once) → Recover (slack, over-wobbly = readable
  vulnerability). Locks target mid-commitment via `CanRetarget`.
- **JellyfishEnemy** — pulse propulsion where animation IS movement: Gather
  (bell inflates) → Contract (squash + single impulse along heading) → Coast.
  Perlin wander with buoyancy bias; eases toward players in menace range with a
  glow telegraph. Sting on contact any time (cooldown-gated). Bell rim ripples
  via `RimOffsets`; tentacles are visual-only ChainSimulators.
- **SquidEnemy** — flashy jet ambusher. Hovers at standoff range; Aim telegraph
  runs chromatophore `_FlashAmount` flicker + mantle inflate; Jet dashes through
  the player (contact damage); InkEscape (low HP or post-hit) fires the ink
  particle burst and jets away. `visualRoot` child rotates toward travel; the
  physics root never rotates.
- **FishSchoolController** — ambient boids, NOT an enemy: one controller Update
  drives all fish transforms (no per-fish Rigidbody/brains); fish are tiny
  chain-strip prefabs that wiggle from motion automatically. Scatters with a
  dart burst when a sub gets close (see `onSchoolScatter` for feedbacks),
  regroups, roam center migrates via Perlin. Pseudo-depth per fish (scale /
  tint / sorting) fakes 2.5D.
- **CrabEnemy** — the first walking creature: rides a height spring above
  raycast ground, LegGaitController walks four IK legs, two brain-driven claw
  IKLegs display state (lazy sway → raised threat → cocked → punched snap).
  Contact damage only during the snap hop. `groundMask` on both brain and gait
  must cover the terrain layers (builder defaults to Default).
  Cliff edges: a probe ahead of travel spots drops; `cliffLeapChance` dials the
  personality (0 = never leaves the platform, 1 = always, 0.25 = mostly stays),
  decision cached a few seconds so he commits. Going over always uses the
  snap-hop lunge — never a plain walk-off. `leapOnlyWhenChasing` (default on)
  restricts the roll to pursuit — patrolling crabs treat edges as walls.
  Chase steering uses a horizontal deadband (`overheadDeadzone`) so a sub
  hovering directly overhead doesn't make him vibrate left-right. While falling (Settle) he does a
  "crab swim": body lilts toward the drift side, claws breaststroke, gait legs
  paddle, and a player inside `airLungeRange` gets lunged at mid-air.
- **AnglerfishEnemy** — deep-water ambush horror: near-invisible dark body,
  glowing lure chain (buoyant free-hanging ChainSimulator) bobbing overhead.
  Tiny strike radius → brief flare telegraph → violent lunge → short chase →
  gives up, goes dark, and re-lights the lure slowly. Uses the ChainSimulator
  `Limp()` hit-reaction for its spent/corpse slack.

## Culling

`Submachina.Core.DistanceCullable` (Scripts/Core) is on every creature prefab:
staggered-interval distance checks against `Submarine.All` (camera fallback),
suspends AI + simulators + renderers + `Rigidbody2D.simulated` beyond ~50 units.
Needed because chunks — and therefore enemies — are never despawned.

## Authoring

The creature prefabs were originally generated by a CreatureBuilder editor script,
since REMOVED — the prefabs in Prefabs/World/Enemy/Procedural and materials in
Art/Creatures are now hand-maintained. Creature materials use the unified
`Submachina/2D/Mesh2DLitSpecular` shader (outline/emission/flash merged from the
retired ProcCreature2D, plus the full specular/normal/Form-Shape stack).
SpawnRule assets live in Data/SpawnProfiles/SpawnRules/Creature*.asset; rules are
NOT auto-added to profiles.

Per-instance colors: add a `SpecularController` (Submachina.Core) — its Mesh
Textures tint and "Outline & Emission" foldouts are the per-instance layer over
the material's shared defaults. `ChainStripRenderer.SetTint` / brains' MPB writes
(`_FlashAmount`, `_EmissionColor`) compose with it.
